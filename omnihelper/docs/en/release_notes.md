## V1.0.0

### Change Description

OmniHelper is a log analysis tool designed specifically for big data platforms, aimed at helping developers and operations personnel efficiently analyze the usage of operators, expressions, and functions in execution logs.
As a supporting component of the Omni ecosystem, this tool can identify mixed execution of native operators and Omni operators, analyze related parameter types, detect unsupported operators/expressions/functions, and generate structured analysis reports to provide data support for performance optimization.

**New Features**

It efficiently analyzes the usage of operators, expressions, and functions in execution logs, generates structured analysis reports, and provides data support for performance optimization.
